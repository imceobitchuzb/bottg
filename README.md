## 🌟 Возможности системы

### 1. ⚡ Прямое исполнение сделок в MetaTrader 5 в 1 клик
- Открытие ордеров (BUY / SELL) по золоту прямо из чата Telegram или из веб-приложения Mini App.
- Автоматический расчет размера лота по формуле риска:  
  $$\text{Lot} = \frac{\text{Риск в \$}}{\text{SL в пунктах} \times 10}$$
- **Интерактивное подключение брокера (`/account`):** поддержка любого MT5 брокера (Exness, Dupoin, IC Markets и др.) с сохранением сессии.

### 2. 🛡️ 24/5 Авто-сканер рынка & Trade Manager
- Фоновый сканер таймфреймов **M5 / M15** каждые 20 секунд.
- При совпадении SMC условий и вероятности $\ge 86\%$ бот мгновенно отправляет Push-уведомление подписчикам с целями входа, SL, TP1, TP2, TP3 и кнопкой исполнения.
- **Автоматический перевод в безубыток (Breakeven):** при достижении TP1 позиция автоматически переносится в безубыток (+5 пунктов прибыли), исключая риск убытка.

### 3. 📈 Статистика и винрейт (SQLite Track Record)
- База данных SQLite (`data/trading_history.db`) фиксирует каждый сигнал и результат в реальном времени.
- Команда `/stats` в боте и вкладка аналитики в приложении показывают текущий винрейт, количество побед/поражений и суммарную прибыль в пунктах.

### 4. 📰 Макроэкономический календарь & Анализ новостей
- Прямой мониторинг мировых новостей (ФРС США, инфляция CPI, занятость NFP, ВВП).
- Индикатор обратной корреляции с индексом доллара (**DXY**).
- Сценарии реакции золота: BUY / SELL при отклонении факта от прогноза.

### 5. 📸 ИИ Vision Анализ графиков (Gemini AI)
- Отправка любого скриншота графика боту для мгновенного разбора.
- Распознавание Order Blocks, Fair Value Gaps (FVG), уровней ликвидности (BSL/SSL) и свечных паттернов.

## 🕒 Настройка режима 24/7 без перерывов

Для бесперебойной работы 24 часа 7 дней в неделю предусмотрено 2 решения:

### Вариант А: На локальном компьютере Windows
1. **Запуск через сторожевой таймер:**  
   Дважды кликните на **`run_24_7.bat`** — скрипт запустит `watchdog.py`, который непрерывно контролирует работу бота. Если произойдет сбой сети или непредвиденная ошибка, сторожевой таймер перезапустит бота за 5 секунд.
2. **Автозапуск при включении ПК:**  
   Запустите **`setup_autostart.bat`** от имени администратора. Скрипт зарегистрирует задачу в Планировщике задач Windows (*Task Scheduler*), и бот будет включаться сам при каждом старте системы.
3. **Отключение спящего режима:**  
   В параметрах Windows (*Питание и спящий режим*) установите значение «Никогда» для спящего режима при работе от сети.

### Вариант Б: На выделенном сервере (Windows VPS)
Поскольку библиотека `MetaTrader5` взаимодействует напрямую с терминалом Windows, для 24/7 автономности без включенного домашнего ПК используется Windows VPS:
1. Арендуйте любой недорогой Windows VPS (ForexVPS, Hetzner, PQ.Hosting, Zomro и др.).
2. Установите терминал вашего брокера MetaTrader 5 и авторизуйтесь.
3. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/imceobitchuzb/bottg.git
   cd bottg
   pip install -r requirements.txt
   copy .env.example .env
   ```
4. Запустите `run_24_7.bat`. Бот будет работать 365 дней в году независимо от вашего домашнего компьютера.
